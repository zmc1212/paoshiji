# 抛石机 PAOSHIJI — 机构复刻 No.14

《元史》襄阳炮(1272,回回人亦思马因所造)——配重式抛石机:配重下落经
杠杆加速抛臂,臂端石弹脱离后按抛体飞行。能量法 ω(θ) 闭式解 + 弹道积分,
射程与理论对照断言。B 键查看复原总图。

## 机构与验算

```
尺寸(演示值):
  抛臂   短臂(配重)0.9 / 长臂 3.4,枢轴高 2.05
  配重箱 200/300/400 kg 可调
  石弹   Ø0.28 · 12 kg,皮窝+垂索挂臂端

能量法(载入期断言):
  惯量   I = m配·Ls² + m臂·Ll²/3 + m弹·Ll² ≈ 690 kg·m²
  角速度 ω(θ) = √(2·m配·g·Δh(θ)/I),Δh = 配重落差(闭式)
  能量守恒:½Iω² + m·g·(Δh₀−Δh) 恒定 ±0.5%

弹道:
  释放   θ=50° → ω=3.55 rad/s(300kg)→ v = ω·Ll = 12.1 m/s,α=46°
  理论射程 R = v·cosα·(v·sinα + √(v²sin²α + 2g·y₀))/g ≈ 19 m
  数值积分(1/120s 欧拉)vs 理论偏差 < 2%(三档配重各断言)
```
